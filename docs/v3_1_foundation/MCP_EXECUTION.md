# XDX Blender MCP: kontrak kemampuan, bukan API yang sudah diverifikasi
Sesi ChatGPT ini tidak mengekspos tool XDX Blender. Nama tool dan argumen aktual harus ditemukan di host yang sudah dipasangkan (mis. Antigravity/Codex). Jangan menebak endpoint/token atau nama metode. Sebelum approval: baca status koneksi dan versi saja bila tersedia. Setelah approval: pastikan digest sama, pastikan izin pengguna benar, baca schema MCP dan pilih aksi yang tersedia. Pemetaan capability: status/version; scene read; scene creation/edit (bpy jika didukung); save .blend; camera/material/rig/animation; render preview; render frame/range; retrieve result atau akses path; inspect logs/report. Bila capability tidak tersedia, status BLOCKED. Jalankan satu smoke test scene/preview setelah approval, bukan render penuh tanpa review. Simpan per-shot logs; validasi hasil aktual via file dan frame. Jangan mengklaim MCP pairing, render atau operasi tanpa hasil tool. Tidak ada bridge baru yang dipasang.
